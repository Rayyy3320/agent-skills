# UI Design Guide

定向合入 [Oil UI Pro](https://ui.oiloil.org/) 0.23.0 设计知识与工具修复的本地定制版，技能名为 `ui-design-guide`，版本为 0.23.0。

为当前 UI/UX 问题按需提供构图、层级、排版、交互与素材知识。相关设计任务可自动调用，也可显式使用 `$ui-design-guide`；多方向探索、独立评审与完整取证按任务需要选择。

具体适用范围和参考入口见 [SKILL.md](SKILL.md)。截图、对比页生成和真实素材检索工具按需使用，依赖要求见 [工具](references/tools.md)。

官方原版独立安装为 `oil-ui-pro`，在 Codex 中保持禁用。本定制版不使用原版更新器覆盖更新；需要同步上游内容时先比较，再按实际需要合入。
