# UI Design Guide

A local customization of [Oil UI Pro](https://ui.oiloil.org/) 0.22.1, registered as `ui-design-guide`.

Apply composition, hierarchy, typography, interaction, and asset guidance to the current UI/UX problem. Relevant design tasks can select it automatically, or invoke `$ui-design-guide`. Direction exploration, independent reviews, and complete evidence packages are chosen according to the task.

See [SKILL.md](SKILL.md) for scope and references. The upstream tools and assets remain available.

The official edition is installed separately as `oil-ui-pro` and disabled in Codex. Do not overwrite this customization with the upstream updater; compare and merge relevant upstream changes when needed.
