# 整理已有页面

在现有视觉语言里修正影响任务的具体问题。用户只要求诊断时不改文件；要求优化时直接处理已授权、可逆的缺陷，只对重要产品取舍询问。

## 定位与修改

1. 读取相关设计依据与实现，在目标视口查看本次涉及的区域；仅在需要前后比较时保留基线截图。
2. 根据这次问题检查相关的布局、层级、控件一致性和状态。长文本、空数据、失败、窄屏和键盘反馈只在它们受改动影响时检查，不默认遍历整页全部状态。
3. 文字溢出、对齐和可读性等已确认缺陷可直接修复。删除业务说明、改变主动作或调整核心流程时，先核实会改变决定的业务信息。
4. 从现有变量、共享组件或造成问题的结构修正；不混入无关重构，不自行更换品牌和视觉系统。
5. 查看修改后的受影响区域，必要时操作相关交互。目标达到就交付，不自动生成多版本对比页或派评审者。

## 交付

简要说明具体问题、改法、验证结果及实质性未验证项。用户要求前后对比时提供对应画面；只更新本次修改影响的现有设计文档，不额外生成诊断报告。
