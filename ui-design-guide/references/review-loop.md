# 评审复核与扩展派发

仅在当前任务确需评审时使用；不因完成页面或改版自动启动。独立评审须符合当前授权与宿主能力，主 Agent 自查也可以使用这里的问题。

## 评审与复核

- 初次反馈以当前任务、设计依据和可观察结果为标准，指出影响目标的具体问题及需要保留的设计。
- 修改后只复核受影响区域和已指出的问题。沿用未变化的有效证据，不重新发起全页盲审或全套取证。
- 评分仅在用户要求时提供，用于解释具体差距，不作为默认完成阈值。
- 目标满足且必要检查通过时结束。进一步评审须能解决尚未确定的实质问题；没有新证据或无可见收益时停止，不追加可选提升。

## 按需选择评审问题

| 当前需求 | 提示词要点 |
| --- | --- |
| 复核修复 | 对照上一轮问题检查新画面，说明哪些已解决，是否产生相关回归；不重新扩展检查范围 |
| 比较多个方向 | 只比较用户要求的差异，区分结构差异与换色，说明哪个更符合目标 |
| 关键任务走查 | 从真实入口完成指定任务，记录阻断、错误操作和缺失反馈 |
| 比较流程方案 | 根据用户目标、步骤和数据语义判断收益及主要失败条件 |

需要具体评审标准时，再读取 [评审手册补充](review-modes.md) 的对应部分。
