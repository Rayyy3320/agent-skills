# 视觉评审派发协议

仅在用户要求独立评审，或当前授权允许且独立意见能解决重要不确定性时派发；完成页面本身不触发评审。

## 交接

给出用户目标、改动范围、已确认约束和当前版本的必要画面。可附可访问的页面地址；只需要静态判断时不额外录屏，只有局部问题时不采集全套状态。沿用未变化的有效证据。

根据问题选读 [评审手册](reviewer-manual.md) 或 [评审手册补充](review-modes.md) 的对应部分；不要求评审者逐项执行全部检查，也不默认评分。缺少独立执行能力时可自查，需要说明独立性的任务才标明未独立评审。

## 处理反馈

按证据、影响和用户目标决定采纳哪些建议。主 Agent 保留判断权，不自动接受“重做”、删文案或可选提升。改动涉及产品取舍或超出任务范围时先解决相关决定。

修复后只复核受影响问题，目标满足或后续尝试没有新依据时停止。需要复核方法时读 [评审复核](review-loop.md)。
