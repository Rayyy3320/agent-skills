# 说服型页面的概念

用于落地页、品牌页、发布页和展览页需要视觉概念的任务。它提供构思方法，不规定候选、子 Agent、素材或验收轮次。

## 概念是什么

把产品希望受众记住的主张表达为一个画面，标题与主视觉共同讲清它。概念应让人看懂、与真实产品有关，并能区分同类。产品功能、按钮、导航和价格仍使用清楚的业务表达。

需要检验概念时看三件事：画面自身能传达主张；标题与画面合起来一读就懂；换成同行的名字后仍能看出差异。主视觉可以表现产品处理的对象或交付的结果，也可以借受众熟悉的事物表达；副标题和后续内容负责把产品说清楚，首屏不必解释所有功能。

## 形成概念

先从现有资料里盘点属于这个产品的具体事物，不为凑数量编造内容。数字产品看真正读写的对象、操作前后的状态变化、关键指标和用户原有工具；实体、空间或文化品牌看名字本意、地域与场所、规格与周期、原材料和真实凭据。画面、区块载体与找图关键词都从这些事实里取。

用一句话做同行替换检验：“这个产品的【具体事物】变成了页面里的【核心视觉、内容载体或交互】。”换成另一家同行后仍完全成立，例如所有分析工具都能套的趋势图、所有工坊都能套的木纹，就还停在品类套话，需要找更具体的依据。

根据当前缺少的设计思路，选择有用的角度：

- 受众来页面前的处境、担心和希望；
- 与产品主张道理相通、受众熟悉的事物；
- 同类产品遗漏的观点；
- 一句话与主视觉之间的关系；
- 其他领域能帮助理解产品的形式。

默认由当前 Agent 形成一个有依据的方向。用户要求比较或重要分歧确需探索时，再提出有实质差异的候选；不默认派五个子 Agent，也不要求先列出固定数量的概念。

## 挑选方向

排除空泛、重复和违背产品事实的方案。按受众理解、品牌辨识度、内容承载与实现成本判断；用户已授权自行决定时选择并继续，不等待无必要的确认。

只为有效比较制作必要的首屏。优先复用真实素材；生成候选与重试由素材是否满足目标以及本次成本授权决定，不为每个方向固定生成多张图。

## 把概念带到首屏以下

从页面需要回答的真实问题出发，例如如何使用、有什么差异、价格和下一步操作，让内容与首屏表达相连。当前 Agent 可直接完成，不自动派多个子 Agent。

用表格、列表或界面实样能更清楚说明的内容照常使用。需要图像时沿用主图的材质、光线、视角或色板；不要为满足屏数而新增插画。只在结构复杂或已有说明需要更新时记录页面结构，不自动创建画面表。

概念也可以影响容器与操作：大字、图像和内容直接排在开放画布上，在有必要的关键位置使用产品专属载体，例如可试用的工作台、对比面板、标本卡或联单。载体取自当前题材，不让每一屏都套同一种卡片。

已有选配、试算或规格切换任务时，让操作与画面、数值或价格同步变化，并检查触屏使用；仅为展示概念的页面不新增业务功能。交互主体的绘制与素材选择见 [素材](media.md)，整页节奏见 [方向贯穿整页](direction-whole-page.md)。

## 整页的图做成一套

1. 优先确认主图能与标题、布局和目标阅读尺寸配合。已有主图足够时直接使用；只有明确偏差才精修或生成替代。
2. 其他必要图像复用主图的视觉规则；能复用或裁切现有素材时不强制新生成。
3. 在实际使用位置检查一致性与可读性。只修复影响当前目标的问题；独立素材评审仅在明确需要且获授权时进行。
